# Overview

## Vision
Create a modular, lightweight, cross-platform game engine focused on:
- Performance
- Simplicity
- Extensibility
- Tooling

## Target Platforms
- Windows
- Linux
- macOS

## Target Graphics APIs
- SDL
- OpenGL (future)
- Vulkan (future)
- DirectX (future)

## Engine Architecture
- Modular subsystems
- ECS-based gameplay
- Event-driven/Signal communication

## Main Priorities
- Fast iteration
- Clean codebase
- Debugging tools
- Editor integration
