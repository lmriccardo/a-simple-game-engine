# Optimization — Phase 1

*Priority: Tier 4, but continuous — keep basic profiling cheap and ongoing through
every tier above; not a terminal step to save for last. See [README](../README.md).
Other phases: [Phase 2](../phase-2/13.2-optimization.md) (GPU profiling, job system),
[Phase 3](../phase-3/13.3-optimization.md) (streaming, ECS cache optimization).*

## Goals
CPU profiling — already done, per [01-Core Engine](01.1-core-engine.md). This doc
exists to say so explicitly and to point at what continuing to use it, rather than
building something new, looks like.

## Current state
**Already built and complete**, as part of [01-Core Engine](01.1-core-engine.md)'s
"Simple profiling system" task: `asge::profiling::TimingBucket`/`TimingProfiler`
([TimingProfiler.hpp](../../../src/ASGE/Core/Profiling/TimingProfiler.hpp)) aggregate
named-scope timing stats (call count, total/min/max nanoseconds) via relaxed atomics
on the hot path, and `ScopedTimer.hpp` provides the RAII wrapper to instrument a
scope with one line. This is a CPU profiler; Phase 1's only real task was already
delivered as part of Core Engine.

## Design notes
- **This phase is "use what exists", not "build a profiler".** The actual ongoing
  work is instrumenting hot paths (`Registry` queries, `MovementSystem`/
  `RenderSystem`, the SDL translation layer) with `ScopedTimer` as they're written
  or touched — a continuous habit, not a discrete milestone to complete once.
- **No frame debugger/visualizer yet** — `TimingProfiler`'s buckets are queryable
  data, but there's no UI surfacing them. [09-UI Framework Phase 1](09.1-ui-framework.md)'s
  debug overlay is the natural place to show them once both exist.

- Profiler output visible somewhere (even a log line) without attaching an external
  tool

## Explicitly out of scope for Phase 1
GPU profiling, a job system ([Phase 2](../phase-2/13.2-optimization.md)); streaming
optimizations, ECS cache optimization ([Phase 3](../phase-3/13.3-optimization.md)) —
none of these have real content/profiling data to justify them yet.
