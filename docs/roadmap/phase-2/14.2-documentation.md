# Documentation — Phase 2

*Priority: Tier 4, but continuous. See [README](../README.md). Other phases:
[Phase 1](../phase-1/14.1-documentation.md) (docs site, doc-comment habit),
[Phase 3](../phase-3/14.3-documentation.md) (full engine manual).*

## Goals
Beginner-facing tutorials — "build your first example" style guides, not just an
API reference.

## Design notes
Worth writing once there's a stable, representative set of examples to walk through
— `examples/` already has several (`ecs_demo`, `input_demo`, `moving_box`, ...)
that could each anchor a tutorial once their underlying systems ([03-ECS](03.2-entity-component-system.md),
[04-Input](04.2-input-system.md)) stop changing shape frequently enough that a
tutorial wouldn't immediately go stale.

## Tasks
- [ ] A "getting started" tutorial walking through building one of the existing
      examples from scratch
- [ ] Tutorials for each MVP-critical system once its Phase 1 is stable
      (ECS, Input already are; Asset Pipeline/Scene Management once they land)

## Deliverables
- At least one beginner tutorial that a newcomer can follow end-to-end against the
  current codebase

## Explicitly out of scope
A full engine manual — see [Phase 3](../phase-3/14.3-documentation.md).
