# Rendering Primitives

## Goals
Extend `IRenderer` with the minimum primitive set needed to draw a scene:
filled/outline shapes, lines, textures, text.
 
## Tasks
 
- [ ] Filled rectangle
- [ ] Line
- [ ] Circle
- [ ] Texture
- [ ] Text

## Milestones
 
### Step 1 — Shapes
- Filled rect
- Line
- Circle (outline + filled)

### Step 2 — Assets on screen
- Texture load + draw
- Font load + text draw

### Step 3 — Validate
- Single demo scene: colored shapes + a sprite + a text label, one frame,
  confirms the full `IRenderer` surface works together

## Deliverables
- `IRenderer` interface extended with the above methods
- `SDLRenderer` implementations
- `ITexture` / `IFont` handle types with clear ownership
- Demo/sanity-check scene exercising all primitives
