A Simple Game Engine, built to stay out of your way.

ASGE is a modular, lightweight, cross-platform 2D game engine written in modern C++ (C++23) on top of SDL3. Small composable subsystems, an ECS-based gameplay layer, and a growing set of runnable examples — targeting Windows, Linux and macOS.

Built around four ideas

Performance

Thin abstractions over SDL3, custom allocators, and a thread pool for concurrent work — the engine tries to stay out of your frame budget's way.

Simplicity

Small, composable subsystems instead of one monolithic framework. Pull in what a game needs through the ASGE.hpp umbrella header.

Extensibility

An ECS-based gameplay layer plus a signal/event system (asge::signals::Signal) for decoupling systems from each other.

Tooling

A debug logger, timing/profiling utilities (ScopedTimer), a virtual filesystem, and a growing set of runnable examples.

Minimal game

A Game<TStateId> subclass drives a stack of IGameStates — TStateId is whatever identifies a screen. See Moving Box for the complete, playable version of this.

main.cpp
#include <ASGE/ASGE.hpp>

class MyGameState : public asge::game::state::IGameState<int>
{
public:
    std::optional<asge::game::state::Transition<int>>
    Update(float inDeltaTime, asge::input::InputState const& inInput) override
    {
        // Game logic goes here
        return std::nullopt; // engaged instead: push/pop/replace to another state
    }

    void Render(asge::video::IRenderer& inRenderer) override
    {
        // Draw calls go here
    }

    void OnSystemEvent(asge::event::SystemEvent const& inSysEvent) override
    {
        // Handle window/system events
    }
};

class MyGame : public asge::game::Game<int>
{
public:
    explicit MyGame(asge::video::IRenderer& inRenderer) : Game(inRenderer)
    {
        SetInitialState(0);
    }

protected:
    std::unique_ptr<StateType> CreateState(int inId) override
    {
        return std::make_unique<MyGameState>();
    }
};

int main()
{
    asge::Application<MyGame> app(asge::ApplicationConfig{});
    app.Run();
    return 0;
}
