MovingBox.cpp
void MovingBox::Update(float inDeltaTime)
{
    // dir is built from the WASD keys
    m_Position += dir * m_Speed * inDeltaTime;
}

void MovingBox::Render(asge::video::IRenderer &inRender)
{
    inRender.DrawRect(
        asge::math::Rect{ m_Position.x(), m_Position.y(), m_Dimension.x(), m_Dimension.y() },
        {255, 0, 0, 255},
        true
    );
}

Performance

Thin abstractions over SDL3, custom allocators, and a thread pool for concurrent work. It stays out of your frame budget’s way.

Simplicity

Small, composable subsystems instead of one monolithic framework. Pull in what a game needs through the ASGE.hpp umbrella header.

Extensibility

An ECS-based gameplay layer plus a signal/event system (asge::signals::Signal) for decoupling systems from each other.

Tooling

A debug logger, timing/profiling utilities (ScopedTimer), a virtual filesystem, and a growing set of runnable examples.
