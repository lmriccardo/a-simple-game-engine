Configure the game window

Tell the editor what size a real build of the game runs at, so the previews match.

Steps

  1. Open View → Game Window (disabled without a project).
  2. Set the target width and height. They are saved in the project's [View] settings.

Previews

  • Every entity with a Camera component gets a live preview box: a world-space rectangle showing exactly what that camera frames at the configured game window size, centred on the entity's visual midpoint (its sprite's bounds, not just its transform's corner) at that camera's zoom. It uses the same math as systems::CameraSystem at runtime but is never applied to the editor's own view.
  • A separate preview anchored at the world origin shows the letterboxed game window itself, regardless of any camera, dimming everything outside it like a real letterbox.
