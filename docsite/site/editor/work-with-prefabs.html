Work with prefabs

A prefab is a reusable template: one root entity with its children, saved to its own file and spawned as many times as you like.

Save a prefab

  1. Select the entity that should be the prefab's root. Its children come with it.
  2. Click Save as Prefab in the Inspector, next to Duplicate.
  3. Choose a name and a folder inside a mounted directory. The editor adds .asgeprefab if you leave it out.

Result: the prefab appears in the Assets panel with its own icon. If the entity had a parent, that link is dropped: a prefab always has exactly one root.

Spawn a prefab

  1. Right-click the prefab in the Assets panel and choose Instantiate (needs an open project and scene).
  2. A copy of the root and all its children appears in the active scene, at the position the prefab was saved with. The root is selected and the scene is marked unsaved.

Every copy is independent: changing one, or the prefab itself later, does not change the others.

Edit a prefab

  1. Double-click the prefab, or right-click it and choose Edit Prefab. A window opens with the prefab's entity tree on the left and an Inspector for the selected entity on the right.
  2. Edit components as usual. Add Child adds a new entity under the selected one.
  3. Click Save to write the file back, reload the asset and close the window. Cancel (or the close button) discards your changes.

The prefab is edited apart from your scene, so the scene does not change until you spawn the prefab again. Copies already in a scene keep the data they were spawned with. The root cannot be deleted, and there is no detach or reparent, so the prefab keeps its single root.

Reference

ItemWhat it does
Save as PrefabInspector button: writes the selected entity and its children to a .asgeprefab file.
InstantiateAssets row menu: spawns an independent copy into the active scene.
Edit PrefabAssets row menu or double-click: opens the prefab editor window.
Reload AssetAssets row menu: re-reads the file the next time the prefab is used.
Load AssetBrings an existing .asgeprefab file into the Assets panel.

The list of prefabs is stored in the .asgeproject file, so save the project (Ctrl+P) to keep a new prefab listed. The prefab files live in your mounted folders like any other asset. How prefabs work in the engine: Scenes.
