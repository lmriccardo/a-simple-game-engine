Navigate the viewport

The viewport is a real, resizable window with the engine's own camera and viewport math underneath, so every overlay pans and zooms exactly like the scene.

InputEffect
Left-dragMove the clicked entity (or drag a gizmo arm to constrain to one axis).
Middle-dragPan the camera.
ScrollZoom, anchored on the point under the cursor.
Restore ViewReset pan and zoom to the default.

Set the grid spacing

  1. Open View → Grid (disabled without a project).
  2. Set the world-space spacing between the reference grid lines drawn behind every sprite.

The value is saved in the project's own [View] settings, not in scene data.
