UI components

A UI widget is an ordinary entity: a UIRect footprint plus the components for what it does. Build them with the asge::game::ui::Create* functions rather than by hand. See the UI theory page and Arrange the UI.

UIRect

The rectangular footprint of a widget, positioned by the entity's Transform (top-left, like Sprite).

TOML table: [UIRect] · Used by: RenderSystem, UILayoutSystem · Source: Game/Components/UI/Common.hpp

FieldDefaultMeaning
m_Size(80, 24)Width and height in Transform units.

Interactable

Pointer state for a widget with a UIRect. Recomputed every frame; m_Clicked is true only on the frame a press completes while still hovered.

TOML table: [Interactable] · Used by: UIInteractionSystem · Source: Game/Components/UI/Common.hpp

FieldDefaultMeaning
m_EnabledtrueFalse opts the widget out of hit-testing (greyed out).
m_Hovered / m_Held / m_ClickedfalseRuntime state. Not saved.

UIButton

A clickable button that changes colour with hover and press.

TOML table: [UIButton] · Used by: UIInteractionSystem, RenderSystem · Source: Game/Components/UI/UIButton.hpp

FieldDefaultMeaning
m_Colorslight button paletteNormal, hover and pressed fill colours.
m_OnClicksignalFired by UIInteractionSystem on click.

UILabel

Text drawn with a baked font. A label with text but no font path is rejected with UIWidgetError::TextWithNoFont.

TOML table: [UILabel] · Used by: RenderSystem · Source: Game/Components/UI/UILabel.hpp

FieldDefaultMeaning
m_Text"Placeholder"The string.
m_FontPathemptyVFS path of the font.
m_FontPixelHeight16Font size in pixels.
m_ColorblackText colour.
m_Align / m_VerticalAlignLeft / CenterHorizontal (Left, Center, Right) and vertical (Top, Center, Bottom) alignment.
m_AutoSizetrueFit the rect to the text.
m_WordWrapfalseWrap to the rect's width; needs AutoSize off.

UICheckbox

A toggle box.

TOML table: [UICheckbox] · Used by: UIInteractionSystem, RenderSystem · Source: Game/Components/UI/UICheckbox.hpp

FieldDefaultMeaning
m_BoxColorslight button paletteBox fill colours by state.
m_CheckColorblackColour of the check mark.
m_CheckedfalseCurrent state.
m_OnToggledsignal<bool>Fires with the new state.

UISlider

A draggable thumb on a track.

TOML table: [UISlider] · Used by: UIInteractionSystem, RenderSystem · Source: Game/Components/UI/UISlider.hpp

FieldDefaultMeaning
m_Min / m_Max0 / 1Range.
m_Value0Current value.
m_TrackColorgrayTrack colour.
m_ThumbColorlight button paletteThumb colours by state.
m_OnValueChangedsignal<float>Fires with the new value while dragging.

UIProgressBar

A bar that fills between a minimum and a maximum. Advance it with Step(bar) or Step(bar, amount): the value is clamped, then m_OnValueChange fires, and m_OnMaxReached fires once it is full.

TOML table: [UIProgressBar] · Used by: RenderSystem · Source: Game/Components/UI/UIProgressBar.hpp

FieldDefaultMeaning
m_DirectionLeftToRightLeftToRight, RightToLeft, TopToBottom or BottomToTop.
m_Min / m_Max / m_Start0 / 1 / 0Range and starting value.
m_DefaultStep0.1Amount added by Step(bar).
m_BackgroundColor / m_FillColor / m_BorderColordark gray / magenta / light grayColours.
m_CurrValue / m_IsAtMaxruntimeCurrent value and whether it is full. Not saved.
m_OnValueChange / m_OnMaxReachedsignalsValue change (with the new value) and reaching the maximum.

UIPanel

A container that draws a background and lays out its children (the entities under it in the Hierarchy).

TOML table: [UIPanel] · Used by: UILayoutSystem, RenderSystem · Source: Game/Components/UI/UIPanel.hpp

FieldDefaultMeaning
m_LayoutAbsoluteAbsolute (children keep their position), Grid (rows, cols), VStack (rows) or HStack (cols).
m_Backgroundshadow blackFill colour.
m_Border / m_BorderColortrue / light grayDraw a border, and its colour.
m_Padding / m_Margin / m_Spacing(0, 0)Inner padding, outer margin and gap between children.

UILayoutItem

Optional, on a child of a panel: how it uses its layout slot.

TOML table: [UILayoutItem] · Used by: UILayoutSystem · Source: Game/Components/UI/UILayoutItem.hpp

FieldDefaultMeaning
m_FillX / m_FillYtrueStretch to fill the slot on that axis.
m_AlignX / m_AlignYStartStart, Center or End within the slot.

UIDebugOverlay

Marks a UILabel as a live min/avg/max FPS and entity-count readout. Create it with CreateDebugOverlay.

TOML table: (never saved) · Used by: UIDebugOverlaySystem · Source: Game/Components/UI/UIDebugOverlay.hpp

FieldDefaultMeaning
m_RefreshInterval0.25Seconds between text updates; also the FPS window.
m_Accumulated / m_Frames / m_MinDelta / m_MaxDeltaruntimeCounters for the current window.
