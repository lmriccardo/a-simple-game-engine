Rendering and animation components

What gets drawn, in what order, and from where.

Sprite

Draws a texture at the entity's world transform. The texture is loaded from a virtual path when assets are resolved.

TOML table: [Sprite] · Used by: RenderSystem · Source: Game/Components/Sprite.hpp

FieldDefaultMeaning
m_VirtualPathemptyVFS path of the texture.
m_SourceRectnoneSub-region to draw; none draws the whole texture (used for spritesheets).
m_TintwhiteColour modulation; the alpha channel fades the sprite.
m_TexturenullResolved texture asset. Runtime only.

RenderInfo

Decides draw order. Higher layers draw on top; within a layer, Y-sort orders by bottom edge so things lower on screen draw in front.

TOML table: [RenderInfo] · Used by: RenderSystem · Source: Game/Components/RenderInfo.hpp

FieldDefaultMeaning
m_Layer0Draw-order bucket.
m_YSortfalseSort by bottom-edge Y within the layer.
m_ScreenSpacefalseDraw in screen space on top of the world; propagates to children.
m_InheritSortFromParentfalseAdopt the nearest ancestor's layer and Y-sort.
m_LocalOrder0Tie-break among entities sharing a sort owner; -1 draws behind the parent.
m_SortOffsetY0Added to the Y-sort key in world units.

Camera

Makes an entity a camera that follows its Transform. The active camera is held in the ActiveCamera resource.

TOML table: [Camera] · Used by: CameraSystem · Source: Game/Components/Camera.hpp

FieldDefaultMeaning
m_Zoom1Uniform zoom.
m_Smoothing0Catch-up rate toward the target; 0 snaps immediately, higher eases in faster.

Animation

Plays a spritesheet clip by writing each frame into the entity's Sprite::m_SourceRect. The frame list lives in a shared, VFS-loaded FrameTable, so many entities can play one clip. While playing, the Animation owns the Sprite's source rect and restores it afterwards.

TOML table: [Animation] · Used by: AnimationSystem · Source: Game/Components/Animation.hpp

FieldDefaultMeaning
m_ClipPathemptyVirtual path of the clip's FrameTable TOML.
m_ClipsemptyNamed clips (idle, run, ...) mapped to clip paths; switch with PlayClip.
m_ClipFrameDurationsemptyOptional per-clip frame duration in seconds, keyed by clip name.
m_FrameDuration0.1Seconds each frame is shown, unless the FrameTable gives a frame its own duration.
m_PlaybackSpeed1Playback-rate multiplier; non-positive stops advancing.
m_LooptrueWrap to frame 0 at the end instead of stopping.
m_StartPlayingtrueWhether a freshly loaded scene starts it playing.
m_Playing / m_CurrentFrame / m_ElapsedTimeruntimeLive playback state. Not saved.
