Audio components

Sound playback. See the Audio theory page.

AudioSource

Plays an audio clip on the machine's output device. Start it with PlayAudioSource; AudioSystem consumes the restart request once.

TOML table: [AudioSource] · Used by: AudioSystem · Source: Game/Components/AudioSource.hpp

FieldDefaultMeaning
m_VirtualClipPathemptyVFS path of the clip.
m_Volume1This source's own gain.
m_LoopfalseRestart the clip when it runs out.
m_PlayingfalseWhether AudioSystem advances playback.
m_RestartfalseSet by PlayAudioSource to force an immediate (re)start.
m_Clip / m_StreamnullResolved clip and its device stream. Runtime only.
