Core components

These describe an entity's identity and place in the world. Almost every scene entity carries a Transform.

Name

A freeform display label. Empty means unnamed.

TOML table: [Name] · Used by: none (editor display) · Source: Game/Components/Name.hpp

FieldDefaultMeaning
m_NameemptyThe label shown in the editor's Entities tree.

Transform

Position, rotation and scale. Local values are relative to the parent (or absolute for a root); world values are what rendering and collision read, recomputed from the local ones by TransformPropagationSystem. Change a local value, then set m_Dirty to request a recompute.

TOML table: [Transform] · Used by: TransformPropagationSystem · Source: Game/Components/Transform.hpp

FieldDefaultMeaning
m_LocalCoordinates(0, 0)Position relative to the parent.
m_LocalScale(1, 1)Scale relative to the parent.
m_LocalRotation0Rotation in radians, relative to the parent.
m_LockedfalseThe editor refuses to move this entity; the engine does not enforce it.
m_WorldCoordinates / m_WorldScale / m_WorldRotationderivedAbsolute values, written by the system. Not saved.
m_DirtyfalseRequest a world recompute.

Hierarchy

Parent/child links. Children form a linked list, so an entity stores its parent, first and last child, and previous and next sibling. Use the helpers in the header rather than writing the links by hand: they refuse to create a cycle.

TOML table: [Hierarchy] · Used by: TransformPropagationSystem · Source: Core/ECS/Hierarchy.hpp

FieldDefaultMeaning
m_ParentNullThe parent, or Null for a root.
m_FirstChild / m_LastChildNullEnds of this entity's children list.
m_NextSibling / m_PrevSiblingNullNeighbours under the same parent.

Disabled

A marker with no fields. Disabled entities are skipped by every view unless it asks for IncludeDisabled(). Disabling an entity disables everything under it; Registry::IsDisabled reports the derived state.

TOML table: [Disabled] · Used by: Registry views · Source: Core/ECS/Markers.hpp

No fields.
