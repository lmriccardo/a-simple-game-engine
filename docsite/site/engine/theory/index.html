Engine theory

What the main parts of a game engine do, and how ASGE implements each one. Every page first explains the concept, then shows the ASGE types that realise it, with a short snippet.

Entity-Component-System

Entities, components, systems and views, and how ASGE's Registry implements them.

Game loop & timing

The main loop, the per-frame system order, game states, the clock and profiling.

Events & signals

SDL event translation, SystemEvent and the type-safe Signal/Connection pattern.

Memory & threading

Linear, pool and stack allocators, the free-list and the ThreadPool.

Input

Keyboard and mouse state, with down/pressed/released queries derived from the event stream.

Rendering

The thin video layer: VideoSystem, IRenderer, textures, cameras and the SDL3 backend.

Audio

The audio device and its stream pool, AudioSource components and the AudioSystem.

Filesystem & VFS

Virtual paths mounted onto real directories, file IO and file watching.

Assets

The AssetManager's path-keyed caches, sprite resolution and spritesheet frame tables.

Scenes

SceneSerializer and SceneManager: saving, loading and switching between levels.

Physics

Colliders, layers and masks, and the movement, collision and trigger systems.

UI

Widgets as entities, the Create* functions, and the interaction and layout systems.

Math

Vectors, shapes, collision tests, easing, tweens and splines.
